# Infinite-Psalm-Generator

This game features rapid light and dark transitions, which may trigger seizures in patients with photosensitive epilepsy. If you have this condition or a family history of it, please play under the guidance of a doctor.

You need to place the corresponding letters in the correct positions according to the code prompts to form words or phrases. Correct code syntax and incorrect syntax will be displayed at the top of the game. When code with a "syntax error" appears, you can only reply with "ERROR" (all uppercase, no quotes). Failure to produce correct output or report errors correctly will have "serious" consequences. For a simpler way to play, you can open your browser's console to see the answers.

You can play directly via the page deployed on GitHub.

This is a game primarily built with AI code. Log about AI are all located in folders name Ai Chat Log.
